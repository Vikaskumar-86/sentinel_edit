# SentinelAPI — Zero-Trust API Security Scanner

SentinelAPI is a React + TypeScript security-audit dashboard for scanning authorized API targets and presenting security findings, risk scores, reports, inventory, vulnerabilities, and scan history.

## Features

- API URL / target scanning
- Uploaded API specification support
- Risk score and risk-level reporting
- Vulnerability findings by severity
- Scan history and reports
- API inventory
- Project dashboard
- Supabase persistence for scan records

## Tech Stack

- React
- TypeScript
- Vite
- Supabase
- `@supabase/supabase-js`

## Installation

```bash
cd sentinel_edit
npm install
npm install @supabase/supabase-js
